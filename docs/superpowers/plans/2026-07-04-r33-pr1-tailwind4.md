# R-33 PR-1 — Tailwind CSS 3.4 → 4.x Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the app from Tailwind 3.4 (PostCSS pipeline, `tailwind.config.js`) to Tailwind 4.x (`@tailwindcss/vite`, CSS-first config) with **zero visual change** — spec §3.1 of `docs/superpowers/specs/2026-07-02-r33-ui-redesign-design.md`.

**Architecture:** Run the official `@tailwindcss/upgrade` codemod for class renames, then hand-finish: translate `tailwind.config.js` into `@theme`/`@custom-variant`/`@utility` blocks in `src/index.css` keeping the **current HSL values byte-identical**, swap `tailwindcss-animate` → `tw-animate-css`, swap the PostCSS pipeline → `@tailwindcss/vite`.

**Tech Stack:** Tailwind 4.x, `@tailwindcss/vite`, `tw-animate-css`, Vite 6.4, React 18, vendored shadcn primitives (14 files in `src/components/ui/`).

## Global Constraints

- **Zero visual change** — current HSL token *values* stay identical; only plumbing changes.
- Dark mode stays class-based on `.dark` (`<html>`), storage key `hf-theme`, pre-paint IIFE in `index.html` untouched (D-F6).
- CI gate: `pnpm lint` + `pnpm build` + `pnpm test` green.
- No AI attribution in commits; plain conventional commits.
- Work happens in worktree `.claude/worktrees/r33-pr1-tw4` on branch `claude/r33-tw4-migration`.
- pnpm via `corepack pnpm` (Node 20; pnpm 11 crashes — see memory).

### Task 2: CSS-first config in `src/index.css`

**Files:**
- Modify: `src/index.css` (full rewrite below)
- Delete: `tailwind.config.js`

**Interfaces:**
- Consumes: Task 1's package state.
- Produces: the complete TW4 config in CSS. Utility names `bg-nutricion`, `text-entreno`, `animate-accordion-down`, `animate-exercise-frame`, `container`, `border-border` etc. must all keep resolving.

- [ ] **Step 1: Write the new `src/index.css`**

```css
@import 'tailwindcss';
@import 'tw-animate-css';

@custom-variant dark (&:is(.dark *));

:root {
  /* ⟨all existing :root HSL custom properties, byte-identical⟩ */
}

.dark {
  /* ⟨all existing .dark HSL custom properties, byte-identical⟩ */
}

@theme inline {
  --color-border: hsl(var(--border));
  --color-input: hsl(var(--input));
  --color-ring: hsl(var(--ring));
  --color-background: hsl(var(--background));
  --color-foreground: hsl(var(--foreground));
  --color-primary: hsl(var(--primary));
  --color-primary-foreground: hsl(var(--primary-foreground));
  --color-secondary: hsl(var(--secondary));
  --color-secondary-foreground: hsl(var(--secondary-foreground));
  --color-destructive: hsl(var(--destructive));
  --color-destructive-foreground: hsl(var(--destructive-foreground));
  --color-muted: hsl(var(--muted));
  --color-muted-foreground: hsl(var(--muted-foreground));
  --color-accent: hsl(var(--accent));
  --color-accent-foreground: hsl(var(--accent-foreground));
  --color-popover: hsl(var(--popover));
  --color-popover-foreground: hsl(var(--popover-foreground));
  --color-card: hsl(var(--card));
  --color-card-foreground: hsl(var(--card-foreground));
  --color-nutricion: hsl(var(--nutricion));
  --color-nutricion-foreground: hsl(var(--nutricion-foreground));
  --color-entreno: hsl(var(--entreno));
  --color-entreno-foreground: hsl(var(--entreno-foreground));
  --radius-lg: var(--radius);
  --radius-md: calc(var(--radius) - 2px);
  --radius-sm: calc(var(--radius) - 4px);
  --animate-accordion-down: accordion-down 0.2s ease-out;
  --animate-accordion-up: accordion-up 0.2s ease-out;
  --animate-exercise-frame: exercise-frame 1.6s ease-in-out infinite alternate;
}

@keyframes accordion-down {
  from { height: 0; }
  to { height: var(--radix-accordion-content-height); }
}
@keyframes accordion-up {
  from { height: var(--radix-accordion-content-height); }
  to { height: 0; }
}
@keyframes exercise-frame {
  from { opacity: 0; }
  to { opacity: 1; }
}

@utility container {
  margin-inline: auto;
  padding-inline: 1rem;
  @media (width >= 96rem) { max-width: 1400px; }
}

@layer base {
  * { border-color: hsl(var(--border)); }
  button:not(:disabled), [role='button']:not(:disabled) { cursor: pointer; }
  body {
    background-color: hsl(var(--background));
    color: hsl(var(--foreground));
    font-family: ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont,
      'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif;
  }
}
```

Notes: keyframes at top level (TW4 keeps `@theme`-referenced keyframes in output); `* { border-color }` replaces TW3's default-border-color behavior (TW4 defaults to `currentColor`); the `cursor: pointer` rule preserves TW3 button cursor UX (shadcn TW4 migration note). Container replicates TW3 `center: true` + `padding: 1rem` + `2xl: 1400px`.
