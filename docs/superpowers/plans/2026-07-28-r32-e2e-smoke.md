# R-32 e2e Smoke Suite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Playwright smoke suite that proves the app boots, authenticates, and renders all 11 spine routes without exploding, running inside the existing `db-test` CI job against the local Supabase stack.

**Architecture:** `e2e/auth.setup.ts` logs in once through the real login form and saves `storageState`; `e2e/smoke.spec.ts` sweeps the routes with three weak assertions (no ErrorBoundary fallback, visible `h1`, clean console). A separate idempotent SQL fixture seeds the QA user + representative rows. The app is built inside `db-test` with the stack's env baked in and served via `vite preview`.

**Tech Stack:** `@playwright/test` (new devDep, Chromium only), raw SQL fixture applied via psql, GitHub Actions (`actions/cache` for Chromium, `actions/upload-artifact` for traces).

**Spec:** `docs/superpowers/specs/2026-07-28-r32-e2e-smoke-design.md`

## Global Constraints

- Worktree: `/home/hudson/dev/hudsons-fitness/.claude/worktrees/r32-e2e`, branch `claude/r32-e2e-smoke`. All commands run from the worktree root.

- Assertions must be locale-proof: never assert on translated copy.
- Deterministic fixture UUIDs use the family `00000000-0000-4000-8000-0000000e2eXX` (XX = hex counter).

- [ ] **Step 2: Create `e2e/smoke.spec.ts`**

Assertion notes: every page renders TWO `h1` elements (mobile top bar + desktop header, one hidden by CSS breakpoint) — `getByRole('heading', { level: 1 })` resolves to the visible one only, because `display:none` nodes are out of the accessibility tree. Never `page.locator('h1')`.

```ts
import { expect, test } from '@playwright/test';

const ROUTES = [
  '/diary',
  '/planner',
  '/templates',
  '/recipes',
  '/recipes/ingredients',
  '/training',
  '/routine',
  '/exercises',
  '/progress',
  '/progress/goals',
  '/settings',
] as const;

// Known-benign console errors. Growing this list requires a comment per entry
// justifying why the error is noise, not signal. Warnings are not collected.
const CONSOLE_ALLOWLIST: RegExp[] = [];

for (const route of ROUTES) {
  test(`renders ${route}`, async ({ page }) => {
    const errors: string[] = [];
    page.on('console', (msg) => {
      if (msg.type() !== 'error') return;
      if (CONSOLE_ALLOWLIST.some((re) => re.test(msg.text()))) return;
      errors.push(msg.text());
    });
    page.on('pageerror', (err) => errors.push(`pageerror: ${String(err)}`));

    await page.goto(route);
    await expect(page.getByRole('heading', { level: 1 })).toBeVisible();
    await expect(page.getByTestId('error-boundary-fallback')).toHaveCount(0);

    // Let data queries land so late console errors are caught too.
    await page.waitForLoadState('networkidle');
    expect(errors, `console/page errors on ${route}:\n${errors.join('\n')}`).toEqual([]);
  });
}
```
